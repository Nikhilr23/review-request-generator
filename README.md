# Review Request Generator
Template-powered SMS and email review-request generator for local service businesses.

**Live after Pages activation:** `https://nikhilr23.github.io/review-request-generator/`

## Why no AI in V1?
The core job is structured enough that good templates solve it without API cost, latency, or sending client details to an AI service. Users can choose Friendly, Professional, or Brief tone and copy the result.

The templates ask for an **honest review** rather than conditioning the request on positive feedback.

## Tech
HTML · CSS · JavaScript. Client-side only.

## V2
Editable templates, business presets, QR-code review link, optional AI variation behind a server-side API route.
